## 🚀 Quick Deployment on GitHub Pages

1. Upload all repository files to GitHub.
2. Go to repository **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** (`main` branch, `/ (root)` folder) and click **Save**.
4. Your live open-source site will be active at:
   `https://<your-username>.github.io/festival-wishes-generator/`
