# Contributing to Festival Wishes Generator

Thank you for your interest in contributing to the Festival Wishes Generator! We appreciate community contributions to make festival greetings more accessible, diverse, and delightful.

## How Can You Contribute?

### 1. Adding New Festival Templates
- Create a new HTML file inside the `festivals/` directory (e.g., `pongal.html`, `onam.html`, `gurpurab.html`).
- Follow the semantic structure of existing festival pages with clear SEO titles, meta descriptions, history/significance, and greeting examples.
- Update `index.html` and `js/app.js` to include the new festival in the interactive generator.

### 2. Improving Accessibility & UI
- Ensure all interactive controls have accessible labels and keyboard navigation.
- Verify WCAG AA contrast compliance across light and dark themes.
- Keep the design clean, fast-loading, and mobile-first.

### 3. Adding Translations
- We welcome translations of greeting templates and festival descriptions into regional and international languages.

### 4. Fixing Bugs & Improving Documentation
- Open an issue for any bugs or suggestions.
- Submit pull requests with clear descriptions of your changes.

## Pull Request Guidelines

1. Fork the repository and create your feature branch from `main`.
2. Ensure code is clean, well-formatted HTML, CSS, and vanilla JavaScript.
3. Test your changes locally across mobile and desktop viewports.
4. Open a Pull Request with a clear summary of your updates.
